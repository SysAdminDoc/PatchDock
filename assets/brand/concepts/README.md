# PatchDock concept exploration

The three raster files in this directory were generated with the built-in ImageGen workflow as independent solid-black concept studies. They are reference material only. The selected idea was manually redrawn as deterministic SVG and Android vector geometry.

## Scorecard

Scores use a five-point scale. Adaptive safety includes mask behavior, single-color behavior, and the ability to preserve negative space at launcher sizes.

| Concept | Silhouette | Product relevance | Originality | 24–32px | Adaptive safety | Total | Decision |

## Generation mode

Built-in ImageGen, one generation per genuinely distinct direction. Every prompt required one centered black mark on a flat white background, three shapes or fewer, strong 24px recognition, and no text, letters, puzzle pieces, arrows, checkmarks, gears, shields, locks, phones, code brackets, package boxes, rounded-square containers, gradients, shadows, texture, 3D, mockups, or watermarks.
